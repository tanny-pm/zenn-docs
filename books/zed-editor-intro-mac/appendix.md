title: "付録：ショートカット＆コマンド早見表"

本書に登場したキーボードショートカットとコマンドパレットのアクションを、機能ごとにまとめました。作業中にど忘れしたときの早見表として使ってください。各行には、詳しい説明のある章も添えてあります。

前提として、キーバインドはMac環境と、オンボーディングでVS Codeキーマップを選んだ状態を想定しています。Zedのキーバインドは**コンテキスト依存**で、同じキーでもフォーカスしている場所によって動作が変わります（たとえば `alt-tab` は、Edit Predictionの受け入れとGitのコミットメッセージ生成の両方に割り当てられていますが、文脈で使い分けられます）。手元の正確な割り当ては、キーマップエディタ（`cmd-k cmd-s`）や `zed: open default keymap` でいつでも確認できます。

## よく使うコマンドパレットのアクション

キーバインドが割り当てられていない操作は、コマンドパレット（`cmd-shift-p`）から名前で呼び出せます。本書で登場した主なアクションをまとめます。

### セットアップと設定

| アクション                    | 内容                             | 章           |
| ----------------------------- | -------------------------------- | ------------ |
| `cli: install cli binary`     | `zed` コマンドをインストール     | 第2章        |
| `zed: show welcome`           | ウェルカムページを再表示         | 第2章        |
| `zed: open settings`          | settings.json を開く             | 第2章・第8章 |
| `zed: open keymap`            | keymap.json を開く               | 第8章        |
| `zed: open default keymap`    | デフォルトのキーマップを表示     | 第8章        |
| `zed: extensions`             | 拡張ギャラリーを開く             | 第3章・第8章 |
| `snippet: configure snippets` | スニペットを編集                 | 第8章        |
| `workspace: toggle vim mode`  | Vimモードの有効 / 無効を切り替え | 第5章        |

### AIエージェント

| アクション                       | 内容                     | 章    |
| -------------------------------- | ------------------------ | ----- |
| `agent: new thread`              | 新しいスレッドを開く     | 第3章 |
| `agent: add selection to thread` | 選択範囲をスレッドに追加 | 第3章 |
| `agent: open settings`           | Agent Settings を開く    | 第3章 |
| `agent: manage profiles`         | プロファイルを管理       | 第3章 |
| `agent: add context server`      | MCPサーバーを追加        | 第8章 |
| `zed: acp registry`              | ACPレジストリを開く      | 第3章 |

### タスク・診断・デバッグ

| アクション                                    | 内容                       | 章    |
| --------------------------------------------- | -------------------------- | ----- |
| `task: spawn`                                 | タスク一覧から実行         | 第6章 |
| `task: rerun`                                 | 直前のタスクを再実行       | 第6章 |
| `zed: open project tasks` / `zed: open tasks` | タスク定義ファイルを開く   | 第6章 |
| `diagnostics: deploy`                         | Project Diagnostics を開く | 第6章 |
| `debugger: start`                             | デバッグセッションを開始   | 第6章 |
| `repl: run`                                   | REPLでセルを実行           | 第6章 |

### Git

| アクション                               | 内容                           | 章    |
| ---------------------------------------- | ------------------------------ | ----- |
| `git: stage and next`                    | hunk をステージして次へ        | 第7章 |
| `git: stage all`                         | すべての変更をステージ         | 第7章 |
| `git: restore` / `git: restore file`     | hunk / ファイルの変更を破棄    | 第7章 |
| `git: unstage`                           | ステージを解除                 | 第7章 |
| `git: commit all tracked`                | 追跡ファイルをまとめてコミット | 第7章 |
| `git: generate commit message`           | コミットメッセージをAI生成     | 第7章 |
| `git: fetch` / `git: pull` / `git: push` | リモートと同期                 | 第7章 |
